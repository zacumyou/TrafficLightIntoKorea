TRAFFIC LIGHT INTO KOREA (TLIK)
기능·사용법 요약 — 로컬 버전 2.3.40 기준
문서 갱신: 2026-09-20


[모드 소개]
Cities: Skylines II의 교차로 신호등을 한국식 외형으로 바꾸는 모드입니다.
교차로별 적용, 도시 전체 적용, 개별 신호등·표지판·부착 요소 편집을 지원합니다.
차량의 통행 규칙이나 신호 주기 자체를 설정하는 모드가 아닙니다.

[필수 에셋과 권장 모드]
- 필수 신호등·표지판 에셋 팩: https://mods.paradoxplaza.com/mods/159257/Windows
  구독 후 현재 플레이셋에서 활성화하고 다운로드를 완료해야 합니다.
- 다음 두 모드 중 하나만 선택하여 구독하는 것을 권장합니다.
  Traffic Tool Essentials: https://mods.paradoxplaza.com/mods/125342/Windows
  Traffic Light Manager: https://mods.paradoxplaza.com/mods/139487/Windows
- 로컬본과 PDX 구독본을 중복 활성화하지 마세요.
- 필요한 에셋을 찾지 못하면 누락 안내가 표시될 수 있습니다.

[기본 사용법]
1. 도로 메뉴에서 한국식 신호등 적용 도구를 선택합니다.
2. 교차로 좌클릭: 한국식 적용 / 우클릭: 기본 신호등 복원.
3. 개별 편집 도구로 신호등을 클릭하여 신호등·표지판·기타 요소를 편집합니다.
4. 완료 후 도시를 저장합니다. 편집 패널은 제목 영역을 드래그해 옮길 수 있습니다.
설치만으로 도시 전체가 자동 변경되지는 않습니다.

[도시 전체 적용·기본 복원]
- 옵션의 '모든 교차로 신호등을 한국식으로 교체하기'는 현재 신호등이 활성화된 교차로를 대상으로 합니다. 꺼진 신호등을 새로 켜지는 않습니다.
- '모든 교차로 신호등을 기본으로 교체하기'는 한국식 적용 지정을 해제합니다.
- 두 작업은 확인창에서 승인한 뒤 실행됩니다. 먼저 도시를 별도로 저장하는 것을 권장합니다.
- 여러 프레임에 나누어 처리하고 진행 상태를 표시합니다. 처리 중 중복 실행을 막습니다.
- 대도시에서는 프레임 저하가 발생할 수 있습니다. 적용 지정 완료 뒤에도 표시용 객체 반영에 시간이 더 걸릴 수 있습니다.
- 기존 '모든 기능 켜기/끄기' 버튼은 제거했습니다. 각 기능은 사용자가 직접 설정합니다.

[자동 에셋 선택과 신호 표시]
- 연결 도로 수와 진행 방향에 따라 일반 3구·좌회전 전용 3구·4구 계열을 선택합니다.
- 연결 도로가 4개 이상인 교차로에서는 4구 계열을 우선합니다. 차로 수와는 다른 기준입니다.
- 개별 편집으로 지정한 에셋은 자동 선택보다 우선하며 자동 선택으로 되돌릴 수 있습니다.
- 실제 신호 상태에 연동한 직진·좌회전 분리 점등과 한국식 전환 표현을 지원합니다.
- 수동 에셋·표지판 교체로 차량 통행 권한이나 신호 주기가 변경되지는 않습니다.

[개별 편집과 Only Ped]
- 신호등 에셋을 수동 선택하고 등화 수·기둥 방향·보행 겸용 여부로 목록을 필터링할 수 있습니다.
- 차량용 신호등도 Only Ped 보행자 전용 에셋으로 외형 교체할 수 있습니다.
- 원래 보행 신호 또는 같은 횡단보도의 호환 신호를 연결할 수 있을 때 해당 보행 상태를 사용합니다.
- 연결할 보행 신호가 없는 위치에서는 정상 점등을 보장하지 않습니다. 외형 교체로 횡단보도나 보행 신호가 생성되지는 않습니다.

[본 신호등·맞은편 신호등 배치]
- 본 위치와 맞은편 각각 앞뒤·좌우 ±3m를 독립적으로 조절합니다. 본 위치 회전은 ±45도, 자동·수동 복제 신호등 회전은 ±90도입니다.
- 슬라이더를 놓으면 적용되며 미세 조절 버튼과 초기화 기능을 제공합니다.
- 맞은편 자동 추가 또는 개별 추가 요청을 지원합니다. 원본 신호 상태에 연동됩니다. 커서로 수동 위치를 지정할 수도 있습니다.
- 안전한 배치 위치를 찾지 못하면 추가 버튼에 붉은 '불가능한 위치'가 잠시 표시됩니다.
- 맞은편이 준비되면 본 위치 신호등만 숨길 수 있습니다. 맞은편 편집에서 본 신호등을 복원할 수 있습니다.
- 맞은편 신호등을 삭제하면 숨긴 본 신호등도 복원됩니다.

[표지판·기타 요소]
- 자동 선택 / 표시 안 함 / 수동 선택을 지원합니다.
- 속도 표지판: 30·40·50·60·70·80·100 km/h.
- 신호 체계: 직좌 동시 / 직진 → 직좌 / 직좌 → 직진.
- 금지 표지판: 직진·좌회전·우회전·유턴 금지. 자동 선택도 이 순서로 우선합니다.
- 에셋에 장착 위치가 있어야 표시할 수 있습니다. 표지판은 실제 통행 규칙을 바꾸지 않습니다.
- 기타 요소는 에셋에 미리 등록된 부착 프롭만 켜고 끌 수 있습니다.
- 도로명 표지판 장착 위치가 있으면 양쪽·왼쪽·오른쪽 유형으로 교체할 수 있습니다.

[저장·기본 복원·다시 적용]
- 교차로 지정과 개별 설정은 도시 세이브와 별도의 JSON 파일에 저장됩니다.
- 기본 신호등으로 복원해도 개별 에셋, 맞은편 생성 선택, 숨김 및 위치·회전 등의 설정은 보존합니다.
- 다시 해당 교차로에 한국식을 적용하면 보존된 설정을 재사용합니다. 전체 적용 버튼은 이전 교차로뿐 아니라 현재 대상 교차로 전체에 적용합니다.
- 기본 복원 후 저장하고 다시 불러오면 기본 상태를 유지합니다. 보존 설정만으로 한국식 적용을 자동 재개하지는 않습니다.
- 관련 교차로는 설정 연결을 유지하기 위해 불필요한 원본 재생성을 피합니다.
- 도로 재건설, 원본 신호등 위치·구조 변경, 에셋 제거 등으로 대상 식별이 달라지면 기존 설정을 연결하지 못할 수 있습니다.
- 설정 파일 손상·누락 시 정상 .bak 백업 복구를 시도합니다. 읽기 실패 시 기존 데이터를 보호하기 위해 설정 저장을 차단하고 오류를 알립니다.
- 늦게 준비되는 교차로·에셋을 위한 제한된 복원 재시도가 포함되어 있습니다. 모든 저장·복원 문제의 해결을 보장하지는 않습니다.

[2.3.36 커서 수동 배치]
- 개별 편집에서 '커서로 복제 신호등 배치 (60m)'를 선택합니다. 커서 위치의 에셋 미리보기를 확인한 뒤 좌클릭으로 확정하고 우클릭으로 취소합니다.
- 본 신호등 기준 수평 반경 60m를 내부 채움 없는 반투명 점선 원으로 표시합니다. 범위 밖 또는 높이 차이 12m 초과 위치에서는 확정할 수 없으며 원이 붉게 표시됩니다.
- 자동 배치의 보도 위치 판정 실패와 관계없이 수동 위치를 지정합니다. 원본당 복제 하나를 유지하며, 이미 복제가 있으면 새 위치로 옮깁니다.
- 선택한 신호등과 같은 에셋을 사용하고 본 신호등의 표시 상태에 연동합니다. 복제 신호등을 개별 선택하여 삭제·에셋 교체·회전 -90~90도 조절이 가능합니다.
- 수동 위치는 JSON에 저장됩니다. 위치 미세 조절도 60m 범위 안으로 제한합니다. 자동 추가 요청/자동 모드로 돌아가면 수동 위치 지정을 해제합니다.
- 배치 도구 종료·저장 시 미리보기를 정리합니다.
- SDK 빌드 및 자동 회귀 테스트로 검증했습니다. 게임 화면에서 배치/점등/세이브 재로드는 별도 확인이 필요합니다.

[2.3.37 임의 배치 미리보기 충돌 수정]
- UI/도구에서 미리보기 객체를 직접 생성·이동하던 처리를 분리했습니다. 객체 검색 목록을 갱신하기 직전 단계에서 생성·이동·삭제를 처리하고 최초 Created/Updated 상태를 보장합니다.
- 커서가 지형을 벗어날 때 숨김 처리, 배치 취소·도구 전환·저장 시 미리보기 정리를 유지합니다.
- 미리보기 요청·생성·최초 이동·삭제를 진단 로그에 기록합니다.
- NativeQuadTree.Update 미등록 객체 갱신을 재현하는 테스트 하네스와 수정된 생명주기를 검증했습니다. 실제 게임 내 재현 검증은 아직 수행하지 않았습니다.

[2.3.38 반복 처리 및 렌더 쓰기 감소]
- 복제 신호등의 매 프레임 점등 경로에서 저장용 SHA-256 키 계산과 교차로 식별 탐색을 제거했습니다. 자동/임의 배치 구분은 생성·재배치 시 보관합니다.
- 개별 설정이 하나도 없으면 설정 식별 탐색을 생략합니다. 표지판 설정은 장착 위치마다 반복 조회하지 않고 한 번 읽습니다.
- 표지판 정기 재검사는 같은 신호등당 초당 최대 4회로 제한합니다. 직접 편집 및 신호 체계 관찰 결과 변경은 기존 요청 큐로 반영합니다. 등화 상태 갱신 주기는 줄이지 않습니다.
- 표지판 부모의 위치·숨김이 그대로면 중복 변환 계산을 생략합니다. 정상 렌더 상태와 동일한 등화 값은 렌더 버퍼에 다시 쓰지 않습니다.
- 진단 로그에 프레임 시간, 저장 키 계산, 위치·숨김 변경, 복구·오버라이드 해제, 등화 쓰기 횟수를 집계합니다.
- 최근 로컬 로그에서는 반복적인 오버라이드 해제 폭주가 확인되지 않았습니다. 에셋 자체의 GPU 부하와 다른 환경의 원인을 모두 배제한 것은 아닙니다.
- 테스트 하네스에서 64개 표시 객체 × 600프레임의 정상 렌더 상태 쓰기가 38,400회에서 0회로 감소했습니다. 실제 게임 FPS 개선 수치는 아직 측정하지 않았습니다.

[2.3.39 캡처 로그 기반 끊김 추가 수정]
