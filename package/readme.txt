TRAFFIC LIGHT INTO KOREA
한국식 신호등으로 바꾸기
기능 및 이용 안내 · 버전 2.3.28 기준

Cities: Skylines II의 원하는 교차로에 한국형 신호등을 적용하는 모드입니다.
도로 구성에 맞는 신호등 자동 선택부터 개별 에셋·표지판 편집, 연동되는 맞은편 신호등 추가까지 지원합니다.
이 모드는 신호등의 외형과 점등 표현을 담당하며 차량의 통행 규칙이나 신호 주기 자체를 설정하는 모드는 아닙니다.

[구독·사용 전 주의사항]
- 기존 도시는 먼저 다른 이름으로 저장한 뒤 사용해 주세요.
- 신호등 및 표지판 에셋 팩을 먼저 구독하고 현재 플레이세트에서 활성화해야 합니다. 모드만으로 모델이 제공되지는 않습니다.
- 에셋은 모드가 참조하는 내부 프리팹 이름과 일치해야 합니다. 표시 이름만 같은 다른 에셋은 대체품으로 인식되지 않을 수 있습니다.
- 기본 신호등 에셋이 누락되면 도시 로딩 후 게임 기본 메시지 창으로 구독 안내와 누락 목록을 표시합니다. 다운로드·활성화 여부를 확인한 뒤 게임을 다시 실행해 주세요.

[주요 기능]
- 교차로별 한국식 신호등 적용 및 기본 신호등 복원
- 교차로 구성과 진행 방향에 따른 일반 3구·좌회전 전용 3구·4구 에셋 자동 선택
- 실제 차로 신호 상태에 연동한 직진·좌회전 분리 점등 및 한국식 신호 표현
- 원본과 연동되는 맞은편 신호등 추가 및 개별 편집

[부가 기능]
- 신호등 에셋 수동 선택과 등화 수·기둥 방향·보행 겸용 여부 필터
- 맞은편 신호등의 앞뒤·좌우 위치 및 회전 각도 조절
- 속도·신호 체계·금지 표지판 선택 및 도로명 표지판 교체
- 부착 프롭 표시 전환과 맞은편 신호등을 남긴 본 위치 신호등 숨김

[기본 사용법]
1. 도로 유지보수 메뉴에서 한국식 신호등 적용 도구를 선택합니다.
2. 교차로를 좌클릭하면 한국식 신호등을 적용하고, 우클릭하면 기본 신호등으로 복원합니다.
3. 개별 편집 도구를 선택한 뒤 신호등을 클릭하면 편집 패널이 열립니다.
4. 신호등·표지판·기타 요소 탭에서 원하는 항목을 편집합니다. 패널은 제목 영역을 드래그해 이동할 수 있습니다.
- 설치만으로 도시의 모든 교차로가 한국식으로 바뀌지는 않습니다.
- 옵션에서 지정한 교차로들을 한 번에 기본 상태로 복원할 수 있습니다.

[신호등 자동 선택 및 점등]
- 연결 도로가 4개 이상인 교차로에서는 직진 가능 여부와 관계없이 4구 계열을 우선 선택합니다. 여기서 기준은 차로 수가 아닌 교차로에 연결된 도로 수입니다.
- 삼거리에서 직진이 없고 좌회전이 있는 진입 방향에는 좌회전 전용 3구 계열을 선택합니다.
- 직진이 가능하고 좌회전이 없는 방향은 일반 3구 계열을 선택합니다. 다만 위의 4개 이상 연결 도로 조건이 우선합니다.
- 개별 편집으로 지정한 에셋은 자동 선택보다 우선하며, 자동 선택으로 되돌릴 수 있습니다.
- 보행 겸용 여부와 설치된 호환 에셋에 따라 실제 선택 결과가 달라질 수 있습니다.
- 기본 좌회전 전용 3구 후보: CSKR3w2lLeftTrafficLightCar01
- 기본 일반 3구 후보: CSKR3w2lTrafficLightCar01
- 실제 차로의 진행·정지·전환 상태를 참고해 직진과 좌회전 표시를 나눕니다. 출발 준비 상태를 임의로 초록불로 바꾸지 않습니다.
- 좌회전 전용 3구도 좌회전 초록불과 빨간불의 동시 점등을 지원합니다.
- 에셋 제작 기준 Layer ID: 빨강 5 / 주황 10 / 일반 초록 15 / 좌회전 초록 50. 좌회전 전용 3구도 좌회전은 50을 사용합니다.
- Spawnable Object 특성은 커스텀 신호등을 구분하는 조건으로 사용하지 않습니다.

[에셋 필터]
- 등화 수: 전체 / 3구(3w) / 4구(4w)
- 기둥 방향: 전체 / 좌 기둥 / 우 기둥
- 용도: 전체 / 신호등만 / 보행자 겸용
- 좌 기둥은 이름 끝이 Left01인 에셋을 뜻합니다. TrafficLight 앞의 Left는 좌회전 전용 신호등을 뜻하므로 서로 다른 구분입니다.

[맞은편 신호등과 배치]
- 자동 추가는 기본적으로 꺼져 있으며 옵션 또는 개별 편집의 추가 요청으로 사용할 수 있습니다.
- 맞은편 신호등은 원본의 신호 상태에 연동됩니다. 아무 곳에나 자유롭게 복제·배치하는 도구는 제공하지 않습니다.
- 횡단보도·도로 방향을 참고해 정렬하며, 세부 배치에서 앞뒤·좌우 각각 ±3m와 회전 ±45도를 조절할 수 있습니다.
- 슬라이더를 놓으면 적용되며, 미세 조절 버튼과 초기화 기능을 제공합니다.
- 맞은편 신호등이 준비된 경우 본 위치 신호등만 숨길 수 있습니다. 맞은편 신호등을 선택해 본 위치 신호등을 복원할 수 있습니다.
- 맞은편 신호등을 삭제하면 숨겨진 본 위치 신호등도 복원합니다.
- 가까운 보행 전용 신호등은 같은 횡단보도 끝점과 호환되는 신호 조건에서 겸용 신호등으로 통합합니다. 단순히 가까운 모든 신호등을 합치지는 않습니다.
- 생성된 맞은편 신호등의 비정상적인 숨김·미표시 상태를 복구하는 처리가 포함되어 있습니다. Anarchy 구독은 필요하지 않습니다.
- 필요한 에셋이나 안전한 생성 위치가 없으면 추가되지 않을 수 있습니다. 정상적인 거리별 렌더링 생략까지 모두 해제하지는 않습니다.

[표지판과 기타 요소]
- 표지판은 자동 선택 / 표시 안 함 / 수동 선택을 지원합니다.
- 속도 제한: 30·40·50·60·70·80·100 km/h
- 신호 체계: 직좌 동시 / 직진 → 직좌 / 직좌 → 직진
- 금지 표지판: 좌회전 금지 / 우회전 금지 / 직진 금지 / 유턴 금지
- 금지 표지판 자동 선택 우선순위: 직진 → 좌회전 → 우회전 → 유턴
- 표지판 변경은 외형에만 적용되며 실제 제한 속도·통행 금지·신호 순서를 변경하지 않습니다.
- 기타 요소 탭에서는 해당 신호등 에셋에 미리 등록된 부착 프롭만 켜거나 끌 수 있습니다. 표시 중이면 초록 체크, 숨김 상태이면 빈 회색 아이콘으로 표시합니다.
- 도로명 표지판 장착 위치가 있는 신호등은 CSKRRoadNameSignBoth / CSKRRoadNameSignLeft / CSKRRoadNameSignRight 중 설치된 에셋으로 교체할 수 있습니다.
- 도로명 표지판은 기존 장착 위치를 유지하며 원래 에셋으로 초기화할 수 있습니다. 원본과 맞은편은 각각 편집할 수 있습니다.

[저장·백업·다른 PC로 이동]
교차로 지정과 개별 편집 설정은 도시 세이브와 짝을 이루는 외부 JSON 파일에도 저장됩니다.
도시를 백업·공유하거나 다른 PC로 옮길 때는 세이브와 해당 JSON을 함께 보관해 주세요.
파일 구분이 어렵다면 아래 폴더 전체를 보관하세요. 다른 PC에도 모드와 필수 에셋이 필요합니다.

[구독 취소 및 기본 상태 복원]
- 원래 게임 신호등을 보존하고 모드가 생성한 표시용 요소는 세이브에서 제외하는 구조입니다. 모드와 에셋을 제거한 뒤 재실행·로드하면 기본 신호등으로 돌아가도록 설계되어 있습니다.
- 수동으로 배치한 커스텀 에셋이나 과거 Spawnable Object 설정 때문에 게임이 직접 배치한 에셋까지 기본 에셋으로 변환해 주지는 않습니다.
- 모든 도시와 모드 조합에서의 구독 취소 결과를 보장하는 것은 아니므로 원본 세이브를 별도로 보관해 주세요.
- TTE·TLM에서 설정한 신호 체계는 이 모드의 복원 대상이 아닙니다.
- 외부 JSON은 구독 취소 후에도 남을 수 있으며, 재설치하면 기존 설정이 다시 적용될 수 있습니다.

- 게임 및 다른 모드의 업데이트나 설정 조합에 따라 결과가 달라질 수 있습니다.
