# Traffic Light Into Korea
## 한국식 신호등 테마

도시의 교차로를 한국식 신호등과 표지판으로 꾸며보세요.
교차로별 적용부터 신호등 개별 편집, 맞은편 신호등 추가까지 지원합니다.

## 구독 전 주의사항

- 적용 전, 기존 도시를 다른 이름으로 저장하여 원본 세이브를 보관해 주세요.
- **필수 신호등·표지판 에셋 팩 (Paradox Mods ID: 159257)**을 함께 구독하고 현재 플레이세트에서 활성화해 주세요.
- 이 모드는 신호등의 외형과 점등 표현을 담당합니다. 차량의 통행 규칙이나 신호 주기 자체를 변경하지 않습니다.
- 교차로 지정과 개별 편집 설정은 별도 JSON 파일에도 저장되므로, 도시를 백업하거나 공유할 때 함께 보관해 주세요.

필수 에셋 팩: https://mods.paradoxplaza.com/mods/159257/Any

## 주요 기능

- 교차로별 한국식 신호등 적용 및 기본 신호등 복원
- 교차로 형태와 진행 방향에 따른 신호등 에셋 자동 선택
- 직진·좌회전 신호 분리 표시 및 한국식 신호 전환 지원
- 기존 신호와 연동되는 맞은편 신호등 추가 기능

## 부가 기능

- 신호등 에셋 직접 선택 및 구수·기둥 방향·보행자 겸용 필터
- 맞은편 신호등의 앞뒤·좌우 위치 및 회전 각도 조절
- 속도 제한·신호 체계·금지 표지판 선택 및 도로명 표지판 교체
- 부속 프롭 ON/OFF 및 맞은편 신호등을 유지한 본 위치 신호등 숨김

## 사용 방법

- 도로 유지보수 메뉴에서 **한국식 신호등** 도구를 선택해 주세요.
- 교차로를 좌클릭하면 적용하고, 우클릭하면 기본 신호등으로 복원합니다.
- 개별 편집 도구로 신호등을 클릭하면 에셋·표지판·배치를 조절할 수 있습니다.
- 맞은편 신호등은 옵션 또는 개별 편집에서 추가할 수 있습니다. 자동 추가는 기본적으로 꺼져 있습니다.
